## 2. Tracks, in the priority order `11` §6 sets

I own **visual family and reliable imports**. I do not own geometry,
rotation, input, callbacks, collision, state timing, placement, the save
schema, or damage volumes. Every track below says what I hand over and
where the seam is.

### Track A — the Glyph interface family *(first)*

**Deliver:** one coherent set for a **live** inventory face — bitmap font
family (body, numerals, headings, keycaps) with metrics; nine-slice panel
blocks; item/slot/state icons; arrow art; and the shared **circuit /
blocked-exit / control** symbol set that U-01, U-11 and PT-17 need.

**Explicitly not:** a painted whole-screen image. Dynamic names,
descriptions, amounts and binds are Godot's text over my panels, never
pixels in my atlas — `04` §3 is explicit and I agree with it.

**The states the symbol set must carry**, from `02` PT-01 and `04` §6:
pending, accepted, refused, moving, blocked, completed — plus the reason
symbols *key*, *power*, *mechanism*, *blocked/unsafe*. Colour is
supplemented by shape, never replaced by it: the dark-green lever/door
example is a **circuit identity**, and two unrelated circuits in one
place must stay distinct when a colour is reused.

**Equipment states** from `04` §5, which the icon set must distinguish:
none owned · owned-not-equipped · equipped-and-empty · pending
authorization · disconnected.

**Evidence I will produce:** Glyph source identity + revision, export
paths + hashes, palette and metrics, state names, atlas/region mapping,
exact `res://` references, and **an in-engine render through the actual
menu consumer at intended size** — including high-DPI and a resize.
`04` §9 and §10 both say a Glyph render is not the proof; I will not
submit one as if it were.

**Tooling discipline:** isolated checkout of `87db9e2`, a **new or copied**
project, granted artist identity distinct from the owner, commands
discovered from `AGENTS.md` / `GAME_ASSETS.md` rather than inferred.
**No original `.glyph` is opened** — my own trial recorded that opening a
`.glyph` checkpoints its WAL and modified six tracked fixtures. Copies
only, diffs inspected.

**What is genuinely new here versus my September trial:** the trial
proved an edit → commit → image → reopen → export cycle at
`87db9e2`. It proved nothing about **bitmap-font and nine-slice import
into Godot 4.5.1**. The guide's font proof names 4.3. That import is the
open technical risk in this track and it is the first thing I would test.
