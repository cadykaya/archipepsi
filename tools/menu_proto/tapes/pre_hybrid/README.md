# Pre-hybrid tapes, kept for the record

*Arty*

These capture and still tapes drove the prototype before the hybrid:
- the functional checkpoint (build `66e18b2`);
- the ROUTE AND ECHO inventory pass (`91e5d3f`).

Their inputs and captions describe that layout, not the hybrid's, so the
default globs of `capture.sh` and `stills.sh` no longer pick them up. To
reproduce those deliveries, check out their commits.

The test tapes (`../test_*.json`) were ported to the hybrid by intent, and
they still run.
