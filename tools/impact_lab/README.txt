ARCHIPEPSI - IMPACT LAB   (revision @REVISION@)

A small TECHNICAL FIXTURE, not a designed room: one hall that tests whether
power, a movement device and a breakable can work together in one real
physical interaction. No enemies. Offline: no bridge, no campaign, nothing
of yours is saved or changed.

START (Windows)
  1. Unzip into one new, empty folder. If it came as two zips (part1of2
     and part2of2), unzip BOTH into that same folder.
  2. Double-click  "START HERE - Impact Lab (Windows).bat"
     (On its first run it joins the two parts into the game and checks it.)
  Nothing to install. Windows may warn about an unsigned program: More
  info, then Run anyway.

CONTROLS
  WASD move - Space jump - mouse look - left click: Static Pulse
  E      use / pick up / put down
  R      back to the start
  Esc    menu: resume, restart the lab, quit

TRY
  Get to what is behind the glass. Then restart (Esc) and try it another
  way round, or try to break it some other way. Sound is on: play at a
  normal listening level.

WHAT IS REAL HERE
  - The thrown object is a real physics body on the engine's own solver:
    it can miss if you change what is on the plate, it can be paused in
    mid-air, and its impact is measured from the speed it actually brings.
  - The shot, footsteps and hit tick now make sound. Crossing D's build
    never connected them; these are the game's existing placeholder sounds.

LIMITATIONS
  - Placeholder looks for the plate and the shutter; the lever and the
    green power line are Arty's candidate kit, as in Crossing D.
  - The existing shot sound is a very short, quiet blip and the recoil is
    small: this build only reconnects them, it does not redesign them.
  - The reward behind the glass is a stand-in: nothing is sent.
