# Shunter sounds v1: sources and licences

Every recording was checked on its own Freesound page on 2026-10-13, for the Freight Bay music. Each page showed **CC0 1.0**, a public domain dedication (https://creativecommons.org/publicdomain/zero/1.0/). CC0 needs no attribution, but every creator is credited here anyway.

Freesound refused connections from this session on 2026-10-16, so the pages were **not re-checked today**. A CC0 dedication cannot be withdrawn, but someone should re-open each page before release, as with the music.

The audio is each sound's public high-quality MP3 preview, the same files the Freight Bay kits came from. They are in `source/raw/`, except the horn, which is the approved file itself.

No game audio, no YouTube audio and no CC BY material is used.
